# 動效目錄 v3（精簡版）

給分鏡 AI 查動效用。每條格式：**編號 名稱**〔作用層〕做法。→ 什麼時候用。
編號沿用 v2，分鏡裡的 `fx` 欄直接寫編號。

**實作標記（superbot-motion，2026-10-17）**：✅ 有對應組件，後面是組件名（參數見 `docs/components.md`）｜◐ 部分做得到，後面寫怎麼做與限制｜沒標記 = 還沒有組件，照 CLAUDE.md 先用現有組件組合或自畫像素圖代替。
原檔在 `D:/桌面/agents/動效目錄_v3.md`（沒有標記）；圖層能力見 `docs/layer3d.md`。

## 畫面基底

| 層 | 內容 |
|---|---|
| 3D 背景 | three.js 場景：low-poly 形體 + 像素貼圖，真實相機做推、拉、平移、升降、俯仰，平滑緩動 |
| 2D 精靈 | 像素角色和道具，硬邊、無抗鋸齒，站在 3D 場景的錨點上 |
| 2D UI | 固定在畫面上的像素 UI：字幕、導航、標題卡、彈窗、標籤、計數器 |
| CSS 光影 | 疊在最上層：bloom 發光、光錐、暗角、景深模糊、色調蒙版、體積光 |

**作用層標記**：〔鏡頭〕three.js 相機｜〔3D〕背景物件或燈光｜〔精靈〕2D 像素精靈｜〔UI〕2D 介面｜〔光〕CSS 光影

**顏色語義（固定）**：金 = 好、價值、正確的路｜紅 = 壞、否定、歸零、被替代｜深藍 = 夜晚、普通的你、還沒開始

**動作節奏**：強調元素（章、標籤、標題卡、選單）瞬間出現或 2–3 幀回彈｜鏡頭和光平滑緩動｜掉落、登場的物件帶彈跳或煙霧｜換舞台用鏡頭或物件轉場，不用淡入淡出

## A. 鏡頭與轉場

- **A1 無限網格縮放** ✅ `CrowdGrid`〔鏡頭＋精靈〕幾十格像素小場景拼成網格，鏡頭持續拉遠直到變成紋理，頂部計數器同步暴漲。→ 海量、大多數人、淘汰。
- **A2 鎖定並推進** ✅ `CrowdGrid`〔鏡頭〕網格變暗 → 某一格被選取框框住 → 鏡頭推進，格子內容放大成下一個場景。→ 從群體聚焦到個例。
- **A3 角括號選取框**〔UI〕四個金色 L 形角標框住目標，出現時略放大再收緊。→ 鎖定、選中。
- **A4 升降 / 推軌** ◐ Layer3D 鏡頭 push（只做輕微移動）〔鏡頭〕沿空間緩慢上升或往前推，兩側物件由遠到近出現。→ 進入大空間、巡覽。
- **A5 先局部再全貌** ◐ Layer3D 鏡頭 pull / pan（只做輕微移動）〔鏡頭〕先近看一個細節，再平移、拉遠看整體。
- **A6 俯仰推入** ◐ Layer3D 鏡頭 push（只做輕微移動）〔鏡頭〕從平視往下俯並推近桌面或地面，目標填滿畫面，約 1 秒。→ 從大廳進入內容。
- **A7 橫向動態模糊擦除** ✅ `scene.transitionOut { type: blur }`〔光〕畫面往一側拖出水平拖影並變暗，下一個場景從拖影中出現。→ 同一舞台內換一個例子。
- **A8 衝擊推入**〔鏡頭〕硬切到極近特寫（大字幾乎出畫），再快速拉遠。→ 引出震撼的標題或引言。
- **A9 色調轉換**〔光〕整個場景瞬間轉成紅色調（或金色調），燈光同步變。→ 崩盤、翻轉，用顏色代替文字。
- **A10 時間流逝** ◐ Layer3D environment.time 補間（天色）；年份跳動用 Counter〔3D〕同一畫面裡鐘針快轉、窗外天色變化，或年份、天數快速跳動。
- **A11 逐格平移巡覽**〔鏡頭〕貼近一排格子，一格一格平移；每格做完全相同的「亮燈 → 動作 → 標籤」，最後拉遠全部亮起。→ 平行列舉。
- **A13 聚光燈收窄** ✅ `Spotlight`〔光〕暗角越收越緊，最後只照亮人物和他手中的物件。→ 收尾、聚焦一人一物。
- **A14 穿越雲層下降** ◐ Layer3D hand ＋ 前後 2D 雲（分層），鏡頭不穿越〔鏡頭〕從暗雲往下穿到亮處，物件或巨手從畫面上方入畫。→ 開場「從天而降」。
- **A15 追隨墜落物**〔鏡頭〕跟著下墜的物件連續穿過 2–3 層不同背景，每層 0.3–0.5 秒。→ 從抽象落到現實。
- **A16 直線擦除揭幕** ✅ `scene.transitionOut { type: wipe }`〔UI〕整張卡往一側擦出畫面，露出下一個場景。→ 快速換畫面。
- **A17 物件衝向鏡頭**〔3D＋鏡頭〕物件沿透視道路衝來，越來越大直到填滿畫面，再切下一場。→ 把數字變成看得見的東西，順便轉場。
- **A18 反向網格拉出** ✅ `CrowdGrid`〔鏡頭＋精靈〕從主角場景拉遠，它縮成網格中唯一的金框格子，四周是暗格，整面網格閃一下紅。→ 主角 vs 大多數人。
- **A19 關燈換時段** ◐ Layer3D room lightLevel ＋ Ambience zzz〔光〕不換場景，燈光硬切成暗，角色閉眼、頭上飄 Z。→ 到了晚上、睡覺時。
- **A20 前景虛焦** ✅ `任何事件的 focus 參數`〔鏡頭＋光〕角色在前景虛化，焦點落在後方道具上。→ 人不重要，看這個東西。
- **A21 圓形遮罩收縮** ✅ `LevelTransition`〔UI〕畫面收成一個圓圈消失，切到下一場。→ 進入關卡。
- **A22 地圖沿路推進**〔鏡頭〕沿地圖虛線路徑平移並推近到下一個節點，角色走到節點旁，接標題卡（C8）。→ 路線式的關卡結構。
- **A23 分割畫面**〔UI〕垂直虛線把畫面切成左右兩半，同一件事兩種處境，各帶一個標籤。→ 同一件事的兩種感受。
- **A24 橫條撐開視窗**〔UI〕黑畫面中出現一條發亮橫條，上下撐開成彈窗。→ 打開系統面板。
- **A25 畫面縮成播放器**〔UI〕整個場景縮成影片播放器，播放數持續跳動，旁邊飄愛心。→ 拿影片本身當例子。

## B. 強調（高亮詞必須觸發其中一個）

- **B1 光環脈衝** ✅ `RingPulse`〔UI〕細線圓環從目標中心擴散，外圍帶點狀粒子，目標閃一下白光，0.4–0.6 秒淡出。→ 高亮詞的預設強調，最常用。
- **B2 標籤彈出** ✅ `Tag`〔UI〕紅底金邊或深底金邊的小牌子瞬間出現在目標旁。→ 給物件下註解。
- **B3 否定章 ✕** ✅ `Stamp（variant x）`〔UI〕紅色像素 ✕ 直接出現，畫面泛紅光。→ 否定、劃掉。
- **B4 發光放大** ✅ `BeamDrop / Sprite glow`〔光〕重要物件出現時帶強烈 bloom，像打了聚光燈。
- **B5 放射光芒** ✅ `SunBurst`〔光〕目標背後出現太陽狀放射光束，持續緩慢旋轉。→ 揭曉答案、獲得獎勵（比 B1 隆重）。
- **B6 蓋章** ✅ `Stamp`〔UI〕紅色印章斜著拍在物件上，帶旋轉角度，瞬間出現。→ 下定論，尤其是負面評價。
- **B7 發光像素大字** ✅ `GlowText`〔UI〕點陣組成的巨大文字，紅或金，帶發光和掃描線；「最好」上方可加王冠。→ 倍數（×N）、強烈的二元對比。
- **B8 警示條**〔UI〕橘黑斜紋膠帶滑入橫跨畫面，再垂下一塊「⚠ …」警示牌；主畫面不變。→ 反方觀點、「也有人不服」。
- **B9 成就解鎖橫幅** ✅ `GamePopup（achievement）`〔UI〕頂部滑下深藍底金邊橫幅：左邊獎盃，右邊「成就解鎖｜名稱」。同類小牌：「解鎖結局｜…」。→ 給觀眾的行動一個遊戲獎勵。
- **B10 MISS 彈字** ✅ `MissPop`〔UI〕角色攻擊障礙，彈出紅色「MISS」，再飄出代價（如「+1 小時」）和汗滴。→ 努力了但沒用。
- **B11 未解鎖卡** ✅ `Tag（variant locked）`〔UI〕灰暗小卡「×N 未解鎖」出現在角色旁。→ 真正的解法你還沒有，埋伏筆。
- **B12 光柱降臨** ✅ `BeamDrop`〔3D＋光〕全黑 → 光柱從上方打下、閃一顆星 → 核心物件降入光中落地，接 B1＋B4。→ 核心物件神聖登場。
- **B13 掛牌價籤** ✅ `Tag（variant hang）/ BigTag`〔精靈〕紅字吊牌晃著掛到角色或物件上。→ 便宜、容易被替代；後段可以用同一種價籤反轉成正面。
- **B14 頭上問號** ✅ `QuestionBubble`〔精靈〕角色頭頂冒出白底「?」泡泡，搭配一句反問。→ 未回答的問題、「你可能會想……」。

## C. 道具與互動

### 揭曉與獎勵
- **C11 卡牌翻面揭曉** ✅ `SkillCard`〔UI〕深色卡背印「?」→ 翻面 → 正面是答案，同時 B1＋B5。→ 揭曉答案。
- **C24 寶箱掉落發牌** ✅ `ChestDeal`〔精靈〕寶箱從頂端掉下彈一下 → 背後放射光 → 開蓋金光 → N 張卡依次飛出、扇形懸浮，金色碎屑飄落，約 1.5 秒。→ 「送你 N 個方法」。
- **C25 技能卡** ✅ `SkillCard`〔UI〕接 C24。推近一張卡 → 翻面 → 頂部「技能 N」、標題寫規則、中間一段小動畫直接演示這一步怎麼做 → 拉回換下一張。→ 分步驟教學。
- **C59 技能卡收納** ✅ `SkillCard / SkillSummary`〔UI〕講完的卡縮小飛到角落排成一列；全部講完後一起扇形展開，標題「已習得 N/N」。
- **C33 獲得物品卡**〔UI〕物件出現後右側彈出 RPG 物品卡：頂部名稱、中間發光圖示和星級、底部等級。→ 給核心概念命名。
- **C54 道具降到手上**〔精靈〕聚光燈下，道具從上方降到角色手中，標籤「○○・交給你」。→ 每關結論。
- **C26 年份累積 + 外殼碎裂進化**〔精靈＋光〕年份標籤快速跳動，物件越來越亮 → 爆光 → 外殼碎成像素方塊飛散 → 露出升級後的樣子，背後升起光柱。→ 長期累積後的質變（高潮）。
- **C62 計數器復活** ✅ `Counter`〔UI〕紅色歸零的計數器變回白字並開始跳動，旁邊掉進一枚金幣。→ 結尾讓核心道具升級。

### 介面互動
- **C6 RPG 對話選單** ✅ `ChoiceMenu / ChoiceDialog`〔UI〕「▶ 選項 A / 選項 B」，游標移動並確認。→ 選擇。
- **C8 關卡標題卡** ✅ `LevelTitleCard`〔UI〕上方白底小字「第 N 關」，下方深藍底大字寫這關的規則；瞬間出現停約 2 秒，離開時帶殘影錯位。→ 進關。
- **C13 轉職面板**〔UI〕「轉職」面板裡職業圖示和名稱快速輪替，每次換都有小爆破，經驗條始終只有一點點。→ 頻繁換方向。
- **C16 確認對話框 + 游標猶豫** ✅ `ChoiceDialog`〔UI〕「是否…？［是］［否］」，手形游標先停在一邊、猶豫，再移到另一邊點擊。→ 誘惑下的選擇。
- **C27 排行榜**〔UI〕RPG 面板滑入，第 1 名先出現並高亮，其餘一行行往下排。→ 用排名呈現差距。
- **C29 關注按鈕** ✅ `GamePopup（follow）`〔UI〕紅色「+ 關注」按鈕（可帶「超級人機 邀請你組隊」框），手形游標點擊後變綠「✓ 已組隊」。→ 請關注。
- **C30 輸入框** ✅ `GamePopup（input）`〔UI〕白色輸入框逐字打出一個填空題，右邊紅色送出按鈕；可先接 C6 選單。→ 請留言。
- **C46 天賦檢測彈窗**〔UI〕標題「✦ ○○檢測」，問題逐字打出，輸入框閃游標 → 讀取條跑滿 → 變成道具圖示＋「獲得：○○」。→ 直接問觀眾，再把答案變成道具。
- **C52「+ 你的」空位**〔UI〕虛線框，中間金色「+」和「你的」，出現時帶光環。→ 你也可以有一個。

### 數量與堆疊
- **C1 掉落堆疊** ✅ `DropStack`〔精靈〕物件一個接一個從上方掉下，落地彈跳揚灰，逐漸堆高。
- **C5 清單點亮**〔UI〕每列舉一項，就點亮一格或一顆寶石。
- **C15 通知堆疊**〔UI〕畫面角落一條條彈出社群通知（頭像＋圖示＋數字），往下堆疊。→ 別人在曬什麼、銷量。
- **C23 逐一閃亮**〔精靈〕一排同樣的物件，第一個亮著，其餘依次閃出星芒。→ 到處都是。
- **C39 素材匯聚成物件** ✅ `CoinFlight`〔精靈〕許多小圖示從來源飛出，聚到一處變成一個物件。→ 這東西是由這些整理出來的。
- **C50 複製機倍增**〔精靈＋UI〕機器吐出一個個複製品，計數 ×1 → ×2 → … → ×10,000，旁邊堆成山，彈出綠標「成本：¥0.00」。→ 零成本複製。

### 狀態變化
- **C2 道具替換** ✅ `PropSwap`〔精靈〕舊道具瞬間消失、新道具出現，背景不動。
- **C3 卷軸展開**〔精靈〕卷軸從捲起狀態展開，露出上面的文字。
- **C4 徽章落下**〔精靈〕徽章從上方掉落到目標上，落定時閃光。
- **C20 連續計數歸零** ✅ `Counter`〔UI〕「○○・連續 N 天」牌子旁有火焰；火焰熄滅，數字抖動碎裂掉落，變成紅色「0」，紅色光環擴散。→ 前功盡棄。
- **C21 全押按鈕**〔UI〕巨大金色按鈕被游標按下，存錢筒裡的金幣像鏈子一樣流進按鈕。→ 一次性投入全部。
- **C22 融化流失**〔精靈〕容器裡的東西融成水，水位上升，原物消失。→ 化掉、流失。
- **C34 降級變形**〔精靈＋光〕物件光芒褪去，變成粗糙普通的材質，形狀不變。→ 真正的價值被隱藏。
- **C35 撿起、猶豫、扔掉**〔精靈〕角色撿起物件、舉起看、頭上冒「…」，然後扔掉。→ 大多數人都放棄了。
- **C41 翻牌計數機** ✅ `Counter`〔3D＋UI〕帶翻牌數字的機器持續跳動，下方有標籤；換標籤即可做對照，歸零時數字變紅「0000」。→ 收入、累積、對照、歸零。
- **C48 黑板年份累積**〔3D〕黑板角落年份快速翻動，板上正字越寫越滿，角落數字同步增加。→ 一輩子累積的上限。
- **C57 鏡子前後對比**〔3D＋精靈〕角色在鏡前做事，頂部進度條；前幾格「第 1 天」「第 30 天」倒影不變，跳到最後一天倒影突然變樣，紅標「換了一個人」。→ 個人成長的質變。
- **C58 雲霄飛車曲線**〔3D〕角色坐在金色軌道的小車上；前段幾乎平、路邊立牌「要不算了？」，之後軌道上彎成指數曲線，車衝出畫面＋光環。→ 前慢後快。

### 比喻物件與場景道具
- **C7 線框展櫃**〔精靈〕玻璃展櫃先以細線框畫出來，內部再出現發光的物件。→ 展示、珍藏。
- **C9 勳章進度**〔UI〕畫面四角圓形勳章，完成的亮金並打勾，未完成的暗灰；進新關前上一枚點亮＋B1。→ 各關獨立的進度。
- **C10 地圖擴張圈地**〔3D〕海面中央小島逐漸長大、長出建築，金色邊框沿邊緣順時針畫出圈住它。→ 範圍、圈子、領地。
- **C12 打孔卡**〔UI〕帶 N 個孔位的金卡滑入，機械臂打一個孔，剩餘次數 −1，打孔處閃光。→ 有限次數、每次都是重大決定。
- **C14 環繞圖示**〔UI〕主體周圍依次彈出小圖示卡片，最後蓋一個紅標。→ 眾人的評價。
- **C17 石碑升起**〔3D〕石碑從地面升起，直排文字從上到下逐字亮起金光。→ 規則、戒律、原則。
