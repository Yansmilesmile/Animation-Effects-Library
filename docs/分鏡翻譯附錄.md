# 分鏡翻譯附錄（給做影片的 agent）

分鏡 prompt（`D:/桌面/CodexTest01/分鏡方案/分鏡prompt_v5.md`）只給分鏡 AI 引擎能力的概要，讓它大膽設計。
下面這些實作限制由做影片的 agent 在翻譯時處理：分鏡寫了做不到的，照這裡的方法改，記進對照報告。

## 一、品牌：`logo：` / `logo角色：` / `書封：`

- **`logo：品牌名`**：用該品牌的官方 logo 原圖轉成像素版。
  1. 原圖來源：先看素材庫 `本期要用到的/`；沒有就從品牌官網或維基百科下載官方 logo（PNG 或 SVG），manifest 的 `source` 填網址。
  2. 轉換：`python scripts/gen-sprite.py <logo.png> --name logo_<品牌> --height <N> --no-key`（原圖已經是透明背景，用 `--no-key` 跳過去綠幕；logo 本身是綠色的，例如輝達，一定要加）。
     原圖是 SVG 或白底的，先轉成透明 PNG 再處理。
  3. 量化後用 Read 看預覽，logo 要一眼認得出來；細節糊掉就把 `--height` 調大。
- **`logo角色：品牌名，動作或表情`**：用 Codex 生圖，把官方 logo 原圖當參考圖附上，要求「以這個 logo 為造型的像素卡通小角色」，再用 `gen-sprite.py` 處理。
  不能生圖時（見 CLAUDE.md「自己做素材」第 4 點），改用像素版 logo ＋ PropFx（彈跳、晃動、發光）代替動作，記進對照報告。
- **`書封：書名`**：同 logo，原圖通常在 `本期要用到的/`。
- logo 疊在像素場景上可以加描邊或陰影，讓它像一張浮起來的圖卡。

## 二、圖層順序（由後到前）

| 順序 | layer 值 | 放什麼 | 座標 |
|---|---|---|---|
| 1 | 負數（如 -3、-1） | 3D 後面的 2D：天空、遠雲、遠景剪影 | 畫面座標 |
| 2 | 3d | 3D 層：整個背景（不透明），或夾在 2D 之間的單一主體（透明） | 3D 場景 |
| 3 | 正數（如 1、2） | 3D 前面的 2D：前景雲、前景植物、遮擋物 | 畫面座標 |
| 4 | back | 角色後面的 2D：整張背景圖、角色腳下的坑、書頁特寫 | 世界座標 |
| 5 | actor | 角色（骨架動畫） | 世界座標，地面線 y = 160 |
| 6 | world | 大部分 2D 組件：標籤、光環、蓋章、掉落物、道具 | 世界座標，跟著 2D 鏡頭走 |
| 7 | hud | 固定在畫面上：大字、標題卡、計數器、選單、字幕、導航、浮水印 | 畫面座標 |

每個舞台最多一個 3D 層。3D 背景是細像素（pixelSize 3–4），角色和重點道具是 2D 粗像素（放大 2–3 倍）。

## 三、3D 層

能做的（細節見 `docs/layer3d.md`）：
- 場景類型 room（牆、地板、窗外夜景、桌椅、吊燈、檯燈、穿衣鏡；lightLevel 平滑開關）、terrain（地面、小路、建築方塊、山坡、樹、路燈；lit 只能全部一起亮）、hand（低多邊形大手：伸出、翻掌、轉手腕、彎手指、張開）。
- environment：時段（夜 / 黃昏 / 白天，可平滑轉換）、天空、星月、雪雨、霧。
- 鏡頭在機位之間 push / pull / pan / hold / cut，只能小幅移動（機位相差 0.5–1.5 公尺）。
- 命名點 `3d:<點名>`：2D 元素擺在 3D 場景的某個位置（預設只取事件開始那一幀的位置；開 `follow` 會跟著鏡頭走，見下面）。
- 內建場景類型只有 room / terrain / hand，但影片專案可以用 `registerLayer3DType` 自寫類型（小米寫了 6 個，見 `D:/桌面/pixel_xiaomi/src/three/`），雲海、海面、燈逐盞亮都做得到。
- 新增 3D 場景類型約小半天，屬於引擎開發，不在做影片的任務裡做（見 CLAUDE.md）。

做不到的，改用 2D：
- 劇情物件的狀態變化（書降下、書頁飛起、卡車開走、閘門升降、石碑升起、數字翻動）→ 2D 組件或素材。
- 路燈一盞一盞亮（C28）→ 在每盞路燈位置依次疊 2D 燈光 Sprite（layer 正數）。
- 2D 元素跟著 3D 鏡頭移動 → 開 `follow`（`layer3d.follow: true`，見 `docs/layer3d.md` 7.2）後推、拉、平移時 2D 會跟著走（只平移不縮放，推拉仍要輕微）；環繞、換成正上方俯視仍不行（2D 是平面）。hud 層不受影響。
- 3D 物件互相遮擋、角色走進 3D 縱深 → 角色永遠站在 2D 地面線上，3D 只當背景。
- 長距離穿越鏡頭（從山上衝進窗戶、跨舞台）→ 2D 轉場。
- 舊的 S3State、S3Camera、S3Focus 不要用；舊系統（stage3d）做的 homescene 不能用。

**角色被遮擋時**：角色站在桌子、講台、攤位後面是用 2D 前景遮罩或遮擋線做的。沒開 follow 時鏡頭一推拉，遮罩和角色不會跟著走，角色會穿模。
- **開 follow＋clipBelow 後可以推拉**：角色 `anchor: "3d:<站位>"`、`clipBelow: "3d:<台面後緣>"`，前景遮罩寫 `follow: "3d:<點>"`，三者一起跟著鏡頭走（只適合正面是水平直線的遮擋物）。
- 沒開 follow：被遮擋的句子 3D 鏡頭用 hold；要換景別就 cut 到新機位，並重新寫角色站位（新機位沒遮擋就讓角色站到前面）。
- 劇情一定要大幅推拉：先讓角色走出遮擋物再推拉，或角色淡出、鏡頭停下後再出現。

## 四、2D 鏡頭

- 只作用在 back / actor / world 層：push / pull / pan / tilt-push / cut；zoom 用 1、1.25、1.5、2、2.5（像素寬度才均勻）。
- 有 3D 層的舞台，2D 鏡頭固定不動，縱深交給 3D 鏡頭。

## 五、UI 擺放

- 每個 UI 元素都有結束時機（本句結束 / 下一句結束 / 換舞台 / 常駐 / 被取代）；分鏡沒寫就到本句結束。
- 同時最多 2 個彈出類 UI；計數器、進度條這類常駐元素每個舞台最多 2 個。
- UI 不擋字幕區（y > 216）、頂部導航（F2）和左上角道具欄（F7）。
