# 新角色規格（給產 SVG 的 AI / 畫師）

照這份交檔，跑一行指令就能變成會做動作的角色：

```powershell
python scripts/auto-rig.py <角色資料夾> --id <角色id> --name "<中文名>"
```

腳本會檢查規格、自動估樞紐、產生 `assets/actors/<id>/`、輸出靜態姿勢圖，並渲染示範影片 `out/<id>-demo.mp4`。
完整範例：`docs/新角色範例/liang_after/`（梁文鋒 after，照這份規格整理過）。

---

## 1. 要交的檔

```
<角色資料夾>/
  front.svg          正面站立（必交）
  side.svg           側面站立，臉朝右（必交）
  poses/<姿勢>.svg   靜態姿勢圖（選交，檔名小寫英文，例如 sit.svg、victory.svg）
```

- **front.svg**：正面、雙腳併攏或微開、**手臂自然垂在身體兩側**、雙手不要碰到身體或互相交疊。表情是平常臉（眼睛睜開、嘴巴閉著）。
- **side.svg**：側面、**臉朝右**、站著（不是走路）：雙腳併攏、靠鏡頭那隻手垂在身側。
- **poses/**：骨架做不出來的姿勢另外交成整張圖，時間軸直接切換成圖。建議交成靜態圖的：坐下、蹲下、躺下、跑步、雙手同時舉高（歡呼、勝利）、張開手掌（阻止、打招呼）、比 V、雙手合握、手拿道具、特殊表情（嘟嘴、哭）。
  骨架已經做得到、**不用另外交**的：走路、招手、指、抱胸、搖頭、點頭、介紹、驚嚇、摔倒、說話（見 `docs/actors.md` 第 3 節）。
- 靜態姿勢圖要和 **front.svg 同一個畫布大小、腳踩同一條地面線、站在同一個水平位置**（直接在 front.svg 的副本上改姿勢最保險），切換時才不會跳。

## 2. SVG 格式

- `viewBox="0 0 寬 高"`，**1 單位 = 1 像素**；座標、寬高都是整數。
- 每個像素用 `<rect x y width="1" height="1" fill="#rrggbb">`，或同色橫向連續的格子合成一條 `<path fill="#rrggbb" d="Mx yH x2V y+1H xZ">`（只接受這種矩形 path）。
- 不要用圓、多邊形、漸層、濾鏡、半透明、`<image>`、文字、transform；背景透明（不要畫底色）。
- 顏色寫 `#rrggbb`。一個角色 20–40 色就夠。
- 每個像素都要放在某個部位的 `<g id="...">` 裡；**同一格只能屬於一個部位**（重疊會報錯）。

## 3. 部位（`<g id>`）

id 全部小寫，直接對到引擎的骨頭。**左右一律用畫面的左右**：`_l` = 畫面左邊那一塊（正面時是角色自己的右手）。

### 正面 front.svg（12 塊都要）

| id | 內容 | 切法 |
|---|---|---|
| `head` | 頭、頭髮、臉、脖子以上 | 下緣切在下巴 / 脖子；頭髮長過肩的，肩膀以下的頭髮放 `torso` |
| `torso` | 身體、衣服、領子、**肩膀圓頭**、腰帶以上 | 包含肩膀頂端那一圈（手舉起來時肩線不會斷） |
| `arm_l_upper`、`arm_r_upper` | 上臂（肩關節到手肘） | **實心的整塊袖子**，不能只有外框線 |
| `arm_l_lower`、`arm_r_lower` | 前臂（手肘到袖口） | 袖口算這塊 |
| `hand_l`、`hand_r` | 手掌（手腕以下） | |
| `leg_l`、`leg_r` | 腿（褲管，髖到腳踝） | 褲襠中線分左右 |
| `foot_l`、`foot_r` | 鞋 | |

### 側面 side.svg（臉朝右）

| id | 內容 |
|---|---|
| `head`、`torso` | 同正面 |
| `arm_r_upper`、`arm_r_lower`、`hand_r` | **靠鏡頭那隻手**（必交） |
| `arm_l_upper`、`arm_l_lower`、`hand_l` | 後面那隻手（選交：三塊都交或都不交；不交 = 用前手壓暗複製，通常就夠） |
| `leg_r`、`foot_r` | **前腳**（靠鏡頭那隻） |
| `leg_l`、`foot_l` | 後腳（大部分被前腳擋住，看得到的部分畫出來就好） |

### 被擋住的部分（`<部位>_under`，建議交）

手臂動起來時，原本被擋住的地方會露出來。把「如果手不在那裡，下面會看到的像素」畫在 `<部位>_under` 群組裡：

- **side.svg 的 `torso_under`（強烈建議）**：側面前手垂下時蓋住的那塊身體（衣服、背部輪廓線）。沒交的話腳本用旁邊的顏色自動補，手往前伸時會看到一塊平平的色塊。
- 其他也可以：例如 `leg_r_under`（被手蓋住的褲子）、正面的 `torso_under`（手臂和身體重疊的地方）。
- `_under` 的格子可以和主部位重疊（只會畫在主部位沒有像素的地方）。

## 4. 表情和嘴型（建議交）

在同一個 SVG 裡加群組，**只畫「和平常臉不一樣」的那幾格**（會蓋在頭上），範圍不能超出 `head`：

| id | 內容 |
|---|---|
| `face_blink` | 閉眼（**至少交這個**） |
| `face_smile` | 笑（眼睛彎、嘴角上揚） |
| `face_surprise` | 驚訝（眼睛睜大、嘴巴 o） |
| `face_lookdown` | 往下看（選交） |
| `mouth_1` | 說話：嘴巴半開 |
| `mouth_2` | 說話：嘴巴全開 |

例：眼睛是 2×2 黑格，`face_blink` 就是「上排兩格改成膚色」那 4 格（下排保持黑 = 閉眼線）。正面和側面各交一套。

## 5. 尺寸

- **直接畫成最後的大小，之後不縮放**（縮小會把 1 像素的線、眼鏡框吃掉；引擎只能整數倍放大）。
- 線條 1 像素；五官最小 1 格。
- 參考高度（腳底到頭頂）：主持人 51、雷軍 64、梁文鋒 before 76、after 85、吉祥物 97。寬鏡頭（畫面高 270）下 85 ≈ 畫面高 1/3，是「主角近景」的上限；要和主持人同框的配角建議 50–70。
- 畫布四邊留 2 格以上空白；腳底那一列是地面線，正面、側面、所有姿勢圖的腳都踩在同一列。

## 6. 自動接骨架做了什麼

- 讀部位 → 檢查（缺塊、重疊、超出畫布、左右反了、袖子只有外框、手臂沒接到身體…），有錯就列出來不產檔。
- 樞紐從部位範圍估：上臂在頂端往下 1/5、前臂 / 手 / 腳在頂端中間、頭在下緣中間、身體繞兩腳中間的髖；腳底中心 = 站位。
- 產生 `assets/actors/<id>/front.svg、side.svg、rig.json`、靜態圖 `assets/generated/<id>_<姿勢>.png`（登記 manifest、`assets.list.json`），跑 `copy-assets` / `actors` / `builtin-assets`。
- 預覽：`out/auto-rig/<id>_front.png`、`_side.png`（右半邊部位上色，白點 = 樞紐，紅線 = 腳底）。
- 示範影片：`out/<id>-demo.mp4`（正面動作、側面走路 / 指 / 抱胸 / 摔倒、切換靜態圖）。`--no-video` 只產骨架。
- 樞紐不滿意：直接改 `rig.json` 的 `pivot` 再跑 `npm run assets`（重跑 auto-rig 會覆蓋，要加 `--force`）。

## 7. 可以直接貼給 Codex 的提示詞

```text
請把附圖的角色做成像素風 SVG，給動畫骨架用。嚴格照下面規格，不要自己發揮：

【要交】
1. front.svg：正面站立，手臂自然垂在身體兩側、手不碰身體，雙腳站直，平常表情。
2. side.svg：側面站立、臉朝右，雙腳併攏，靠鏡頭那隻手垂在身側。
3. poses/<英文小寫>.svg：<列出要的特殊姿勢，例如 sit=坐下、victory=雙拳舉高>。和 front.svg 同畫布大小、腳踩同一列、站在同一個水平位置。

【格式】
- viewBox="0 0 寬 高"，1 單位 = 1 像素，座標全整數；角色高（腳底到頭頂）<N> 像素，畫布四邊留 2 格。
- 每個像素用 <rect width="1" height="1" fill="#rrggbb">，或同色橫向連續合成 <path d="Mx yH x2V y+1H xZ">。不要圓、多邊形、漸層、半透明、transform、背景色。
- 線條 1 像素，20–40 色。
- 每個像素都放進下面其中一個 <g id>，同一格不能出現在兩個群組。左右用「畫面」的左右（_l = 畫面左邊）。

【front.svg 的 12 個群組】
head（頭和頭髮，切在下巴；過肩的長髮放 torso）、torso（身體、衣服、肩膀圓頭）、
arm_l_upper / arm_r_upper（上臂，實心整塊袖子，不能只有外框線）、arm_l_lower / arm_r_lower（前臂含袖口）、hand_l / hand_r（手掌）、
leg_l / leg_r（褲管，從褲襠中線分左右）、foot_l / foot_r（鞋）。

【side.svg 的群組】
head、torso、arm_r_upper / arm_r_lower / hand_r（靠鏡頭的手）、leg_r / foot_r（前腳）、leg_l / foot_l（後腳，只畫看得到的部分）。
另外加 torso_under：假設前手不在，前手後面那塊身體會長什麼樣（衣服顏色 + 背部輪廓線），只畫被手擋住的格子。

【表情（正面、側面各一套）】只畫和平常臉不同的格子：
face_blink（閉眼）、face_smile（笑）、face_surprise（驚訝）、mouth_1（嘴半開）、mouth_2（嘴全開）。

交檔前自己檢查：每個群組都在、沒有重疊的格子、側面臉朝右、手臂是實心的、所有圖腳底在同一列。
```

## 8. 常見錯誤訊息

| 訊息 | 怎麼改 |
|---|---|
| 缺 arm_l_lower | 少交那一塊（或 id 拼錯）。 |
| 部位重疊：A 和 B 都有像素 (x,y) | 同一格出現在兩個群組，刪掉其中一個。 |
| 有 N 個像素沒有放在任何部位的 `<g id>` 裡 | 把散落的像素歸到某個部位。 |
| 不認得的部位 id「jacket」 | 只能用第 3、4 節的 id；外套屬於 torso / 手臂。 |
| 左右反了 | `_l` 是畫面左邊。 |
| 不支援 `<circle>` / path 只能是矩形格式 | 換成 `<rect>` 或矩形 path。 |
| （注意）只填滿外框的 30%，像是只有外框線 | 袖子要實心填色。 |
| （注意）沒有碰到 torso | 部位之間要相鄰，否則轉動時會分開。 |
| （注意）沒交 torso_under | 側面手往前伸時身體會露出平色塊，補交 `torso_under`。 |
